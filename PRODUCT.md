# Session Desk

Session Desk helps developers find, inspect and manage their local Claude Code and
Codex conversations. It keeps files on the user's machine, uses recoverable removal,
and installs as one Python tool. The existing package and command remain compatible.

The primary job is finding a past conversation, inspecting it and copying the command
to continue. Review and cleanup are secondary, explicit operations. Memories are
searchable and recoverable through the same interface. No account or hosted service.

This surface is an Operate application used repeatedly on desktop and occasionally
on mobile. A synthetic demo makes every main interaction safe to evaluate for a
portfolio visitor without installing either provider. The demo never reads real roots.

The approved redesign includes English/Spanish, light/dark, keyboard access, a compact
summary and list/detail layout, typed boundaries, packaged frontend assets, automated
checks and external architecture/contribution documentation. No code comments.
