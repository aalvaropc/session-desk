# Changelog

## 0.3.0 — Session Desk

- Background `start`, `status` and `stop` commands with detached startup, authenticated
  lifecycle control, private logs/state and concurrent-launch protection.

- New compact workbench with session/conversation detail, coherent mobile layout,
  native keyboard controls, accessible actions, English/Spanish and light/dark themes.
- Typed provider, catalog, recovery, HTTP and CLI boundaries; frontend source and assets
  separated from Python. Source explanations moved to external documentation.
- Managed memory trash and restoration, collision-free identities, legacy recovery,
  resumable multi-file operations and malformed provider metadata handling.
- Synthetic demo that is safe to inspect and export without provider installations.
- Self-contained static HTML and bundled wheel assets; the package and command use
  the Session Desk name.
- Regression checks for browser persistence, keyboard/filter behavior, API/storage,
  packaging and supported environments; contribution and architecture documentation.

## 0.2.0

- Claude Code and Codex session discovery, direct loopback deletion and recoverable trash.
- Provider filters, memory browser, static exports and unchanged-transcript caching.
