# Session Desk visual system

Mode: Operate. Direction: a compact reading desk for developer conversations.
The app's identity comes from the overlapping-page mark, a quiet blue selection and
a list/detail composition that makes titles and conversation text the main material.

Use bundled IBM Plex Sans (400/500/600), system monospace for paths and identifiers,
14px body text, 24px page titles, compact 12px metadata, tabular figures. Outer layout
uses a 216px pale neutral navigation rail and a flexible work area. The conversation
panel is a native-feeling companion to the list, not an overlay on desktop.

Light: near-white ground, white working surface, dark ink, slate-grey secondary text,
blue #255cbd only for selected content and key actions. Dark: neutral charcoal layers,
o navy cast. Reds signal destructive actions, greens only successful operations.
Surfaces use subtle rules or tone steps, no decorative shadows or gradients.

Use one outlined SVG icon family with a consistent 1.65px stroke. Controls have visible
focus, meaningful labels, 40px minimum hit areas, restrained corners and clear disabled
states. Summary counts form a compact sentence/strip, not metric cards. Bulk actions
appear only for selected items. Row selection, review classification and deletion are
separate behaviors. Mobile moves navigation into a top strip and detail into one pane.

The authored motion is a short detail-panel entrance; reduced motion removes travel.
Errors remain readable until dismissed, dialogs preserve focus, and all local storage
has validated fallbacks. Both language dictionaries own all interface copy.
